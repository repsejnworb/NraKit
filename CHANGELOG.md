# NraKit 0.20.0

### New
- Campfire timer: also works in a sleeping bag. The bar counts your Well-Rested stacks up to 3 and turns green (with the sound) when you're fully rested. After the first stack it also knows how long the rest takes, and shows the time left. It can be turned off in its settings. /nra preview sleepingbag shows it.

Type /nra new in game to see what's new in every version.
